# VoiceBean · web demo

Connect to a soundcore Work (D3200) recorder over Bluetooth from your phone, then download and play its recordings.

- Open: https://qianxi66.github.io/luyindou-demo/start.html
- iPhone: needs the free Bluefy browser (Safari on iPhone has no Web Bluetooth). Android: use Chrome.
- Everything is processed on your phone; nothing is uploaded.

This repository only contains the built static web files. Demo only; not an official Anker or Feishu product.
